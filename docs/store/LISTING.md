## Description
**NYXOR needs an AI model to answer.** Either a model running on your own PC (a local model server such as Ollama, installed separately; no account or key needed), or, optionally, an API key from a cloud AI service you already use. An internet connection is needed only for cloud models, web research and video generation.

NYXOR is a workspace for talking to AI models. It stores your chats, memories and API keys on your PC in an encrypted file. The publisher runs no server, has no accounts and receives no data from the app.

What you can do:
• Chat with local or cloud models, one at a time or as a council that compares several.
• Let NYXOR choose a model for each message and see why, with automatic fallback if a model fails.
• Research current topics: NYXOR searches with a search service you connect, reads the pages and writes a cited answer.
• Attach images, documents and code; the AI can create files you can download and preview.
• Optional voice control and spoken answers.
• See measured readings of your PC (CPU, memory, disk) and of your models while you work.

**AI-generated content.** NYXOR uses live generative AI. Answers come from the model you connect, not from the publisher, and can be wrong or inappropriate. Every answer has a Report button. You decide which kinds of data may leave your PC (first-run screen and SYSTEMS → PRIVACY); local models send nothing anywhere.

**The agent.** An optional AGENT mode can read and write files and run commands on your PC, only with a local model, only in folders you allow, and only after you approve each action.
