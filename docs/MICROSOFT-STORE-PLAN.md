# NYXOR on the Microsoft Store: plan, policy check and status

First written 15 Nov 2026 against **Microsoft Store Policies v7.20** (effective 22 Oct 2026), read in full from Microsoft Learn; updated after the 2.3 compliance work.
Not legal advice. Every submission is judged against the policy version current at the time, so re-read the policies the day you submit.
Related files: `docs/store/LISTING.md`, `docs/store/CERTIFICATION-NOTES.md`, `docs/store/SUBMISSION-CHECKLIST.md`, `privacy.html`.

## 1. Where it stands
The program-side blockers I found are fixed and tested. What remains cannot be done here: Windows packaging and testing, the trademark check, your account, hosting the privacy policy, and your own support email. Nothing here guarantees approval; it removes the reasons I could find for rejection or removal.

## 2. What was verified and what was not
Verified in this session: the text of Store Policies v7.20; individual developer registration is free (Windows blog, Sep 2025; a May 2026 Microsoft blog says the company fee was removed too, while some Learn pages still show $19 / $99, so check at signup); a packaged Win32 app needs the restricted capability `runFullTrust` with a justification; a live US trademark registration for NYXOR exists (Reg. 8050751, Class 11, a Shenzhen company; a quick web check, **not a clearance**), and a UK application for NYXION (Class 9 software) is close in sound.
Verified by tests here (Linux): everything under "Done in code" below.
**Not verified:** anything on Windows (the MSIX build, WebView2 or Edge app window, the Windows code paths for CPU/memory readings, the Windows App Certification Kit). Whether reviewers treat LLM API keys as "financial information" (10.8.3) is my reading of the text. I could not confirm any Partner Center encryption or export-compliance question.

## 4. Making the single file and the Store package
- **The single file:** `python build_single_file.py` writes `dist/nyxor.pyz` (about 150 KB), a standard Python zipapp holding the program, interface and privacy page. Run it with `python nyxor.pyz` (Python 3.11+). It marks itself as the Store build, keeps data in `%LOCALAPPDATA%\NYXOR`, and never writes inside itself. Pass `--support-email`, `--privacy-url` and `--publisher`. `--dev` leaves the Store limits off.
- **The Store package (needs Windows, not done here):** an MSIX must contain an executable. Suggested route, all untested: embed Python (the python.org "embeddable package") plus `nyxor.pyz`, or wrap them into one `nyxor.exe` with a bundler such as PyInstaller (a build-time tool only; the backend stays stdlib-only), then package with the Windows SDK's `makeappx` (or the MSIX Packaging Tool), declare `runFullTrust` and `internetClient`, and let the Store sign it (policy 10.2: certificates are yours "unless provided by Microsoft Store signing"). Alternative (10.2.9): submit a signed installer URL instead.
- Install on a clean Windows 10/11 VM, follow `CERTIFICATION-NOTES.md`, check that uninstall removes the app, and run the Windows App Certification Kit before submitting.
